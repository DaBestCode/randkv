# Security policy

## Supported versions

RandKV is pre-release software. Security fixes are applied to the latest commit
on `main` until the first stable package release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
**Security → Report a vulnerability** flow for this repository. Include the
affected version, model/backend configuration, reproduction steps, and impact.

Expect an acknowledgement within five business days. No disclosure timeline is
promised until the report has been reproduced and its impact assessed.
